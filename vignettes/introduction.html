This vignette gives a short introduction to creating customizable CPB style figures with ggcpb.

1 What is ggcpb?

ggcpb is the new version of James. It draws figures in the CPB house style from Excel or from R.

1.1 Why ggcpb instead of James?

ggcpb is more future proof. It is built on ggplot2, the most widely used plotting package in R. This brings the following benefits:

  • More possibilities. Anything ggplot2 can do, ggcpb can do. If you need an extra layer or a special annotation, you can add it. It allows for new figure types that were not possible with James, such as a donut chart.
  • Easier to maintain. ggcpb adds a thin layer to a well tested package.

1.2 What you need to know to use ggcpb in Excel

This is the general workflow to create figures with ggcpb without using R:

  1. Find the most recent ggcpb version.
  2. Copy it to the place where you want to create figures.
  3. Put your datasets in the folder data. Open params.csv in Excel and describe your figures.
  4. Start run_import.bat by double clicking it. Your figures appear in the folder generated.

You do not need to know R to follow this workflow. One parameter file and one or more datasets drive everything.

  • params.csv describes your figures. Column 1 holds the parameter names, such as title, x and data. Every other column describes one figure. The row data names the dataset of the figure. All parameters and their descriptions are given in the import vignette.
  • The folder data holds your datasets. Each dataset is its own CSV file with any name, such as koopkracht.csv. The first row holds the column names. The following rows are the observations per column.

Add the row page to save a figure at full width (15.5 cm). The default is half (7.5 cm). Write the dataset name without .csv, such as koopkracht. Leave data blank to use data/data.csv. Write a;b to draw the same figure for both datasets. A figure is saved under the name of its dataset, so koopkracht gives koopkracht.png. If two figures use the same dataset, the figure number is added, such as koopkracht_1.png.

Please note: The files must be saved as CSV, not as spreadsheet (xlsx). In Excel, choose File -> Save as -> CSV UTF-8 (comma delimited).

Run the script again after every change. This will update the figures. The import vignette gives a more detailed explanation and lists all settings per figure type. See vignette("import").

1.3 Use ggcpb in R

Next to plotting Excel data with ggcpb, you can also plot data that you already have in R. The caption below each figure in this introduction shows the function to use. Load the packages first.

library(conflicted) # optional, but recommended
library(ggcpb)

Each figure type has its own function.

# Line chart
cpb_line(data = df, x = year, y = value)
# Bar chart
cpb_col(data = df, x = year, y = value, fill = group)
# Area chart
cpb_area(data = df, x = year, y = value, fill = group)
# Box plot
cpb_box(data = df, x = group, p5 = p5, p25 = p25, p50 = p50, p75 = p75, p95 = p95)
# Dot plot
cpb_dot(data = df, x = term, y = estimate, lower = lower, upper = upper)
# Donut chart
cpb_donut(data = df, fill = group, y = share)
# Scatter plot
cpb_scatter(data = df, x = income, y = spending)
# Histogram
cpb_hist(data = df, x = duration)
# Map
cpb_map(data = df, region = code, value = share)

To export a figure, use save_cpb(). It writes the figure at the CPB page widths. Use page = "half" for 7.5 cm and page = "full" for 15.5 cm.

save_cpb("zonnepanelen.png", p, page = "half")

The rest of this introduction assumes that you work in Excel.

2 Figure types

Each figure below is combined with a feature that you can also use with several other plot types, if not all. The parameters and their corresponding values are portrayed next to the figure. Other settings keep their default.

It is possible to set the style for a whole publication. Dutch is the default. An English report can use style = english in params.csv, or options(ggcpb.style = "english") in R.

2.10 Classed map

The maps can display municipalities or provinces on bundled generalised CBS/Kadaster boundaries. The following map colours each Dutch municipality by class. The parameter cut makes the classes, and cut_labels = pct writes them as percentages. In R, cpb_cut() and label_pct_nl() do the same. The boundaries come with the package.

gemeenten <- tibble(code = unique(cpb_nl_geo("gemeente")$code)) |>
  mutate(aandeel = runif(n(), 5, 75),
         klasse  = cpb_cut(aandeel, breaks = c(0, 20, 30, 40, 50, 60, Inf),
                           labeller = label_pct_nl()))

Relevant parameters

plot_type map
title Aandeel huishoudens met zonnepanelen
region code
value aandeel
cut 0;20;30;40;50;60;Inf
cut_labels pct
palette blues
legend_title aandeel

How to reproduce this figure: copy params.csv, run_import.bat and the folder data with map.csv to a personal folder. Fill in the parameters above in params.csv and start the script. In R you can call cpb_map() instead. Follow the example code in section 4.10 to create the plot in R. Alternatively, the csv file can be read with read.csv() and used as input to cpb_map().

More options are in vignette("maps").

3 Ggplot2 base allows for endless possibilities

Every ggcpb figure is a real ggplot2 object. This means you can stack extra functionalities to the plot in R with +.

The next figure has a sharp rise between 2020 and 2021. We add a reference line, and a text along the diagonal in dark pink italic letters. The position comes from the coordinates of the data. The angle follows the slope of the line.

stijging <- tibble(jaar = 2017:2024,
                   waarde = c(2.1, 2.3, 2.0, 1.9, 6.4, 6.8, 6.5, 6.6))

cpb_line(stijging, x = jaar, y = waarde,
         title = "Een scherpe stijging", ylab = "%") +
  geom_hline(yintercept = 6, linetype = "dashed", linewidth = 0.3) +
  annotate("text", x = 2020.2, y = 4.2, label = "scherpe stijging",
           angle = 72, colour = "#a0004e", fontface = "italic",
           size = 2.4, family = cpb_font_family())

You can stack as many pieces as you need. More patterns are in vignette("annotation").

4 Example code to create figures in R

The code below creates the figures above in R. It first builds the data, then draws the figure. It is the same code that made the figures in this document. Start the script with these lines.

library(conflicted)
library(ggcpb)
library(ggplot2)
library(dplyr)
library(tidyr)

4.1 Line with forecast

groei <- tibble(jaar = 2015:2027,
                groei = round(rnorm(13, 1.5, 0.8), 1)) |>
  mutate(marge = c(rep(0, 9), 0.4, 0.9, 1.4, 1.8),
         lo = groei - marge, hi = groei + marge)
cpb_line(groei, x = jaar, y = groei, ymin = lo, ymax = hi,
         forecast_x = 2023.5,
         title = "Economische groei met onzekerheid", ylab = "%") +
  scale_x_continuous(breaks = seq(2015, 2027, 3), minor_breaks = 2015:2027,
                     guide = guide_axis(minor.ticks = TRUE))

4.2 Columns with two axes

erfenissen <- expand_grid(
  soort = factor(c("geen aangifte", "wel aangifte"),
                 levels = c("geen aangifte", "wel aangifte")),
  jaar  = 2015:2022
) |>
  mutate(mld = c(15.0, 15.3, 15.5, 16.3, 19.4, 20.5, 22.2, 23.0,
                 5.8, 5.6, 5.6, 6.6, 6.4, 6.5, 6.8, 7.0)) |>
  left_join(tibble(jaar = 2015:2022,
                   heffing = c(1.7, 1.8, 1.8, 1.8, 2.3, 2.4, 2.5, 2.6)),
            by = "jaar")
cpb_col(erfenissen, x = jaar, y = mld, fill = soort,
        sec_y = heffing, sec_limits = c(0, 3),
        sec_legend_label = "erfbelasting", sec_ylab = "mld euro",
        title = "Erfenissen en erfbelasting", ylab = "mld euro")

4.3 Horizontal bars with chosen colours

groepen <- c("tot 120% wml", "120% wml tot modaal", "1 tot 1,5x modaal",
             "1,5 tot 2x modaal", "2 tot 3x modaal", "boven 3x modaal")
zonnepanelen <- expand_grid(
  jaar  = factor(c(2021, 2024), levels = c(2024, 2021)),
  groep = factor(groepen, levels = rev(groepen))
) |>
  mutate(aandeel = c(10, 14, 19, 22, 26, 33,
                     19, 25, 31, 38, 47, 59))
cpb_col(zonnepanelen, x = groep, y = aandeel, fill = jaar,
        position = "dodge", orientation = "horizontal",
        colour_index = c(2, 1), value_limits = c(0, 70), width = 0.85,
        title = "Zonnepanelen naar inkomen",
        ylab  = "inkomensgroep", xlab = "aandeel binnen inkomensgroep (%)")

4.5 Boxplot

raw <- tibble(
  groep      = factor(rep(groepen, each = 400), levels = rev(groepen)),
  koopkracht = rnorm(2400, mean = rep(c(-3, -1.5, 0, 1, 2, 3.5), each = 400),
                     sd = 2)
)
kk <- raw |>
  summarise(p5 = quantile(koopkracht, 0.05), p25 = quantile(koopkracht, 0.25),
            p50 = quantile(koopkracht, 0.50), p75 = quantile(koopkracht, 0.75),
            p95 = quantile(koopkracht, 0.95), .by = groep)
cpb_box(kk, x = groep,
        p5 = p5, p25 = p25, p50 = p50, p75 = p75, p95 = p95,
        orientation = "horizontal",
        title = "Koopkracht per inkomensgroep",
        subtitle = "inkomensgroep", ylab = "% koopkrachtmutatie")

4.7 Dot plot

termen <- c("Werken ontmoedigd", "Ongelijkheid", "Hard werken loont",
            "Leeftijd", "Geslacht", "Kinderen")
schatting <- tibble(
  term = factor(termen, levels = termen),
  blok = factor(rep(c("Percepties", "Achtergrond"), each = 3),
                levels = c("Percepties", "Achtergrond")),
  coef = c(3.2, 2.9, -2.0, 3.5, 0.4, -1.4),
  lo   = c(-0.3, 2.1, -3.0, 2.6, -1.3, -3.3),
  hi   = c(6.6, 3.6, -1.1, 4.3, 2.2, 0.6)
)
cpb_dot(schatting, x = term, y = coef, lower = lo, upper = hi,
        group = blok,
        title = "Samenhang met voorkeurstarieven",
        xlab  = "%punt verandering")

4.8 Scatter plot
