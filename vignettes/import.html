1 Introduction

Figures can be created directly with or without using R. This vignette described the method to create figures using only Excel.

To create a figure, you need:

  • a params.csv file
    • this is the parameter file, which specifies which figures to create and how they should be configured
    • one params.csv can contain the parameters for several figures
  • a data folder with the dataset(s)
    • each dataset is a CSV file
  • the run_import.bat script

Please note: The datasets must be saved as CSV, not as spreadsheet (xlsx). In Excel, choose File -> Save as -> CSV UTF-8 (comma delimited).

1.1 How to create a figure without opening R?

The general workflow to create figures with ggcpb is as follows:

  1. Find the most recent ggcpb version.
  2. Copy it to the place where you want to create figures.
  3. Put your datasets in the folder data. Open params.csv in Excel and add your parameters.
  4. To create a figure, double clik on run_import.bat. This reads params.csv, builds every figure and saves the images in the folder generated. Each image is named after its dataset. Running the script again produces updated figures. Images with the same name are replaced. A dataset or figure that fails is skipped and listed at the end, and in params_log.txt. The other figures are still saved.

R and ggcpb must still be installed on the computer running the script.

The parameter file refers to variables by their column names. Categorical columns (e.g. regio, geslacht) keep the order of the rows in the created figure. So, the first group in the CSV-file (e.g. here werkenden) is the first on the axis and in the legend.

3 The parameter file

The parameter file determines which figures are created. Each figure has a plot_type, together with the settings required for that plot type. The parameter data names the dataset of the figure.

The first column holds the parameter names. Every other column describes one figure. This is the example parameter file. The first row, with the plot types, is the header.

plot_type col line
title Koopkrachtontwikkeling naar groep Werkloosheid
x jaar jaar
y koopkracht werkloosheid
fill groep
ylab % mutatie %
position dodge
sec_y werkloosheid
sec_type line
sec_legend_label werkloosheid
sec_ylab %
create y y
data koopkracht werkloosheid
style english

This table shows that there are two figures. The first figure (see figure 1) is a column chart (plot_type = col) that uses the koopkracht dataset (data) and that portrays werkloosheid on the second y-axis (sec_y). The second figure (see figure 2) is a line chart (plot_type = line) that uses the werkloosheid dataset (data) and has no secondary y-axis. A parameter value can be left blank, such as sec_y in the second plot. Only the second figure sets style to english, so it gets English labels and number formats.

The parameter page sets the page width a figure is saved at: half (7.5 cm, the default), full (15.5 cm) or small. If left out, the default half is used.

3.1 Plot types

plot_type names the figure type: line, col, area, box, boxplot_extended, dot, scatter, hist, donut or map. Each type is in R the cpb_ function of the same name, such as cpb_line(). Every argument of that function can be a parameter. Appendix A lists them all per plot type.

3.2 Special values

Most values are plain text, a number, TRUE or FALSE. A few need a special form:

Value Example What happens
a list 0;100 ; separates the values.
a line break First sentence\nsecond sentence \n starts a new line.
no upper limit 0;20;Inf Inf and -Inf are numbers.
a formatter euro x_labels and sec_axis_labels take number (1.000), euro (€1.000) or pct (1%). Own labels such as a;b;c work too.
pairs p5:onderste 5% dot_labels takes name:value pairs.
a date 2024-01-31 A dataset column of dates gives a date axis. 31-1-2024 works too.

3.3 Classes

The parameter cut puts numbers into classes, such as 0;20;30;40;Inf. That gives the classes “lager dan 20”, “20 - 30”, “30 - 40”.

With style = english it gives the classes “below 20”, “20 - 30”, “30 - 40” and “40 and above”.

The parameter cut_labels says how the class limits are written:

  • number (default) writes plain numbers, such as “20”.
  • euro adds a euro sign, such as “€20”.
  • pct adds a percent sign, such as “20%”.

The classes colour the figure through one column. This is value of a map, colour of a line, dot or scatter plot, and fill of the other types. The numbers themselves stay available, for example on the y-axis.

3.4 Saving

Next to page, four parameters say how a figure is saved:

Parameter Example What happens
height 10 The height in cm. Left out, the page height is used.
preset map map makes a map as tall as it needs. presentation is for slides.
dpi 800 The resolution. The default is 300.
lock FALSE A title that is too wide only gives a warning, instead of an error.

4 Creating the figures using R

Pass the parameter file to cpb_import_csv(). The datasets are read from the data folder next to it:

figure_dir <- file.path(tempdir(), "figures")
params_csv <- file.path(figure_dir, "params.csv")
figs <- cpb_import_csv(params_csv)

When the parameter file contains multiple figures, cpb_import_csv() returns a named list. The names come from the datasets. Here the two figures use different datasets, so they are called koopkracht and werkloosheid.

save_cpb() precisely positions the secondary-axis caption in the koopkracht figure, so the figure is saved using save_cpb() rather than printed directly.

path <- tempfile(fileext = ".png")
save_cpb(path, figs$koopkracht, page = "half")

5 Several datasets

The parameter data names the dataset of a figure, relative to the data folder next to params.csv. The extension .csv is optional, so koopkracht and koopkracht.csv are the same dataset.

Parameter data What happens
koopkracht The figure uses data/koopkracht.csv.
koopkracht;werkloosheid Two figures are made: one from data/koopkracht.csv and one from data/werkloosheid.csv.
blank The figure uses data/data.csv.
column absent The same as blank.

The figures are named after their dataset. If several figures use the same dataset, the figure number is added to the name. The first figure column in params.csv is number 1. For example, koopkracht_1.png and koopkracht_3.png.

A named dataset that does not exist in the data folder is skipped with a warning. Nothing falls back to another dataset. The other datasets in the same list and the other rows are still created. With data set to a;b;c and no b.csv, you get figures for a and c, and a warning about b.csv.

5.1 A parameter file with one figure

A parameter file can describe a single figure or several figures. When describing only one figure, it has one column of values next to the parameter names. For example, the following describes a line chart. It can be saved in the same folder, so it finds the same data folder:

params_one <- file.path(figure_dir, "params_one.csv")

writeLines(c(
  "plot_type,line",
  "title,Werkloosheid",
  "data,werkloosheid",
  "x,jaar",
  "y,werkloosheid",
  "ylab,%"
), params_one)

cat(readLines(params_one), sep = "\n")
#> plot_type,line
#> title,Werkloosheid
#> data,werkloosheid
#> x,jaar
#> y,werkloosheid
#> ylab,%

When the parameter file describes one figure, cpb_import_csv() returns that figure directly rather than a named list. Use simplify = FALSE to always get a named list.

fig_one <- cpb_import_csv(params_one)

6 Handling problems

A parameter can be left blank. In that case, the default value is used.

If a parameter is not valid for the selected plot_type, it is ignored and the default is used. This produces a warning.

If a figure cannot be created, for example because a column referenced by a parameter does not exist in the dataset, that figure is skipped. Other figures in the same parameter file are still created.

Each call to cpb_import_csv() also writes a log file next to the parameter file. The log records parameter problems and figures that were created or skipped.
